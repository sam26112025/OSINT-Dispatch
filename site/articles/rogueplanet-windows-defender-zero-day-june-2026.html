RoguePlanet: Microsoft Defender Zero-Day Exposes Fully Patched Windows 10 and 11

File No.IGRS-064/2026
SubjectTechnical analysis of the RoguePlanet zero-day exploit and defensive guidance for Windows environments
CategoryThreat Intelligence
AuthorManuj Kumar Pandey
Published2026-06-12
Reading time6 minutes

A new Microsoft Defender zero-day named RoguePlanet was publicly released hours after June 2026 Patch Tuesday, granting SYSTEM-level privileges on fully patched Windows 10 and 11 machines. Here is what it does and what defenders should do now.

What happened

On June 10, 2026 — the same day Microsoft released its monthly Patch Tuesday security updates — an anonymous security researcher operating under the alias Nightmare Eclipse published a new proof-of-concept exploit named RoguePlanet. The timing was not coincidental. The exploit targets a race condition vulnerability in Microsoft Defender and, when successful, produces a command shell with SYSTEM-level privileges on Windows 10 and Windows 11 machines — including those fully updated with the June 2026 security patches.

ThreatLocker independently confirmed they were able to reproduce the exploit, validating that it is not merely theoretical. The exploit was published after GitHub and GitLab removed the researcher's prior repositories, following Microsoft's public condemnation of the disclosures.

How the exploit works (conceptually)

RoguePlanet exploits a race condition in the way Microsoft Defender's remediation process handles files. When Defender identifies a potentially malicious file and begins its remediation routine, a brief window exists during which the exploit can redirect the cleaned file to an attacker-controlled path — specifically targeting wermgr.exe (Windows Error Reporting) in the System32 directory. If the race is won, the attacker's code runs under the Defender engine's elevated privileges, resulting in a SYSTEM shell.

The exploit currently functions only on desktop versions of Windows (10 and 11). The researcher noted it does not reliably work on Windows Server in its current form, though they believe the underlying vulnerability exists there as well.

Context: the Nightmare Eclipse campaign

RoguePlanet is the seventh public zero-day proof-of-concept released by Nightmare Eclipse since early April 2026. Previous releases include BlueHammer (CVE-2026-33825), RedSun, UnDefend, YellowKey, and GreenPlasma — several of which have been observed in real-world exploitation after publication. Microsoft fixed GreenPlasma and YellowKey in the same Patch Tuesday that RoguePlanet followed. The pattern — patching previous disclosures as new ones drop — represents an unusually public and adversarial disclosure dynamic.

Detection signal: An interactive shell with SYSTEM integrity whose parent process is MsMpEng.exe (the Defender engine) should never occur in a healthy Windows environment. If your EDR or SIEM sees this parent-child process relationship, treat it as a high-priority alert.

What defenders should do

  • Apply June 2026 Patch Tuesday immediately — it does not fix RoguePlanet, but it does address GreenPlasma and YellowKey which have confirmed wild exploitation
  • Enable application allowlisting — ThreatLocker confirmed their allowlisting controls blocked the RoguePlanet attack by default, even on machines where the PoC could execute the race condition
  • Monitor for MsMpEng.exe spawning child processes — this is the primary detection indicator; configure your EDR to alert on this process lineage
  • Restrict local user privileges — the exploit requires local access; standard user accounts with enforced least privilege reduce the attack surface significantly
  • Control SMB share access and removable media — the exploit can be triggered via specially crafted VHD/VHDX files or malicious SMB shares

India-specific relevance

Indian enterprises and government departments running Windows 10 and 11 workstations — which includes the vast majority of corporate and government desktop environments — are affected by this vulnerability. Organisations that delay patch deployment due to change management cycles should prioritise the June 2026 cumulative update and add the MsMpEng.exe process lineage detection rule to their SOC monitoring as an interim measure.

Current patch status

As of June 12, 2026, there is no patch specifically addressing the RoguePlanet race condition. Microsoft is expected to address it in a future update. Monitor the Microsoft Security Response Center (MSRC) and CERT-In advisories for updates. The June 2026 Patch Tuesday cumulative update remains the most important immediate action — it addresses 197 other vulnerabilities including two previously disclosed Nightmare Eclipse zero-days that have confirmed wild exploitation.
