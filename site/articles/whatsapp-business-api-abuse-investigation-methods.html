WhatsApp Business API Abuse — Investigation Methods for Cybercrime Units

WhatsApp Business API has become a major vector for cybercrime in India. Unlike regular WhatsApp, the Business API allows programmatic message sending at scale — making it ideal for phishing campaigns, OTP fraud, investment scams, and digital arrest extortion. Understanding how fraudsters abuse this system, and how investigators can trace them, is increasingly critical.

What is WhatsApp Business API?

WhatsApp Business API (now called WhatsApp Business Platform or Cloud API) allows businesses to send messages at scale through approved Business Solution Providers (BSPs). Legitimate uses include OTP delivery, order confirmations, and customer service. Fraudsters abuse it by:

  • Registering fake businesses through BSPs using forged documents
  • Using compromised BSP accounts to send fraudulent messages
  • Exploiting template approval delays to send phishing messages
  • Using "Meta Business Suite" compromised accounts

How Fraudsters Operate

The BSP Exploitation Model

BSPs (Business Solution Providers like Gupshup, WATI, Interakt, 360Dialog) provide API access to businesses. Fraudsters create fake companies, submit forged GST certificates and business registration documents to BSPs, obtain API access, and then launch campaigns before the BSP detects fraud.

Compromised Business Accounts

Fraudsters phish legitimate business owners' Facebook/Meta accounts, gain access to their WhatsApp Business API accounts, and use existing approved templates to send fraudulent messages. The messages appear to come from legitimate businesses.

Template Abuse

WhatsApp templates must be approved by Meta. Fraudsters create templates that appear legitimate (e.g., "Your KYC is pending — click here to update") and get them approved before Meta detects the intent. Once approved, they deploy at scale.

Investigation Methodology

Step 1: Identify the BSP

From the WhatsApp message, identify the WABA (WhatsApp Business Account) ID. This is embedded in the message metadata. The WABA ID reveals the BSP through Meta's business lookup. Common BSPs in India:

  • Gupshup — gupshup.io
  • WATI — wati.io
  • Interakt — interakt.co
  • AiSensy — aisensy.com
  • Kaleyra — kaleyra.com

Step 2: Meta Legal Process

Submit a Law Enforcement Request to Meta:

  • Portal: facebook.com/records — requires registration as LE agency
  • Emergency requests: facebook.com/records/login — for imminent harm
  • Data available: Account registration details, IP logs, phone number, business verification documents
  • Response time: 15-30 days standard, 24-72 hours emergency

Step 3: BSP Investigation

Once BSP is identified, issue Section 91 BNSS notice to the BSP's Indian office:

  • Account registration details of the fraudulent business account
  • KYC documents submitted (business registration, GST, director ID)
  • IP addresses used to access the BSP dashboard
  • Payment details (bank account/card used to pay for API access)

Step 4: Phone Number Forensics

  • WhatsApp numbers are tied to SIM cards — TAFCOP lookup for Aadhaar linkage
  • CDR request for the WhatsApp registered number
  • Last seen location from CDR cell tower data
  • International numbers — MLAT process or Interpol notice

Evidence Preservation

  • Export WhatsApp chat with "Include media" — preserves all attachments
  • Hash the export file immediately (SHA-256)
  • Screenshot individual messages with timestamp visible
  • Preserve message metadata by forwarding to email before deletion
  • Request server-side records from Meta — client-side deletions do not affect server logs

Proactive Detection

For intelligence teams, monitoring WhatsApp Business API abuse requires:

  • Subscribing to Google Safe Browsing and PhishTank for URLs appearing in WA messages
  • Monitoring honeypot phone numbers that receive bulk messages
  • Coordinating with CERT-In for WhatsApp phishing reports
  • Using IGRS IOC Feed to track India-targeted phishing domains sent via WA

Conclusion

WhatsApp Business API abuse is a rapidly evolving threat that requires investigators to understand both the technical infrastructure and the legal processes for obtaining data from international platforms. The key advantage investigators have is that API access leaves a rich paper trail — BSP registration, payment records, IP logs — that physical cash-based crime does not. Early identification of the BSP and immediate legal process is critical before account data is purged.
