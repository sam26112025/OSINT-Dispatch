Advanced Google Dorking: Operators and Techniques for Serious OSINT

File No.IGRS-030/2026
SubjectComprehensive guide to advanced Google search operators for professional OSINT investigation
CategoryOSINT Fundamentals
AuthorManuj Kumar Pandey
Published2026-05-20
Reading time6 minutes

Google's search operators are among the most powerful — and most underused — tools in the OSINT toolkit. The full operator set, with investigative use cases for each.

Beyond basic search

Most people use Google as a natural language search engine. OSINT investigators use it as a structured query language against the world's largest document index. Search operators transform generic keyword searches into precise queries that can find specific file types on specific domains, pages containing specific combinations of terms, or content that has been indexed but is not intended to be public. Mastery of Google's operator set is a foundational OSINT skill that requires no special tools and costs nothing.

The essential operators

site: — restricts results to a specific domain. site:company.com filetype:pdf finds all indexed PDFs on a domain. site:linkedin.com/in "Company X" "Director" finds LinkedIn profiles of Company X directors. Invaluable for scoping searches to known-relevant domains.

filetype: — restricts results to specific file types. filetype:xlsx site:gov.in finds Excel files on Indian government sites. Common investigatively useful types: pdf, xlsx, docx, csv, sql, log, txt, xml. File types sometimes expose data not intended for public access.

intitle: / allintitle: — restricts results to pages with the search term in the title. Useful for finding specific document types: intitle:"index of" "parent directory" finds directory listings. allintitle:confidential salary budget 2025 finds pages with all those terms in the title.

inurl: / allinurl: — restricts results to pages with the term in the URL. inurl:admin login finds admin login pages. inurl:/wp-content/uploads/ filetype:pdf finds PDFs uploaded to WordPress sites.

intext: / allintext: — searches within page body text specifically. Useful when the search term may appear in navigation or other elements you want to exclude. intext:"Aadhar" intext:"PAN" filetype:csv (investigative example — finding potential data exposures).

cache: — returns Google's cached version of a page. Invaluable when content has been removed or modified since indexing. cache:domain.com/page.

related: — finds pages similar to a specified URL. Useful for finding competitors, related organizations, or alternative sources. related:company.com.

" " (exact phrase): — requires exact phrase match. The single most important operator for precision. Always use for names, document titles, specific terms.

- (exclude): — excludes pages containing the specified term. Useful for removing noise: "John Smith" lawyer -"John Smith and Sons".

Combining operators

The real power emerges from combining operators. site:company.com filetype:pdf "confidential" -inurl:public finds confidential PDFs on a domain, excluding those in public directories. site:linkedin.com/in "Company X" "Head of Security" OR "CISO" finds security leadership at a specific organization. intitle:"index of" "backup" site:targetdomain.com checks for exposed backup directories — a classic vulnerability check used in authorized security assessments.

Dorking ethics: Google dorking on your own organization's assets (authorized audit), a subject of a lawful investigation, or public records is appropriate OSINT practice. Using dorking to access private data, systems, or content you are not authorized to access is unlawful regardless of how the information was found.
