IoT and Smart Device Forensics in India — Investigation Guide

The Internet of Things (IoT) has created a new frontier for digital forensics in India. Smart TVs, CCTV cameras, smart speakers, home routers, and connected vehicles now generate evidence that can be crucial in criminal investigations — from alibis to cybercrime tracing to physical crime evidence.

IoT Evidence Sources in India

  • Home routers: DHCP logs, DNS queries, connected device history
  • CCTV/IP cameras: Video evidence, access logs, metadata
  • Smart TVs: Viewing history, app usage, login credentials
  • Smart speakers (Alexa/Google): Voice command history, location data
  • Smart meters: Energy usage patterns (occupancy evidence)
  • Fitness trackers: Location history, activity data, health metrics

Router Forensics

Home routers are often overlooked but contain valuable evidence:

  • DHCP leases — which device had which IP at what time
  • DNS query logs — websites visited by all connected devices
  • Connection logs — when each device connected/disconnected
  • Port forwarding rules — evidence of server operation or tunneling

Extraction requires admin access (password) or factory reset with forensic imaging. Most consumer routers log to memory only — power loss destroys logs. Prioritize router in time-sensitive cases.

CCTV Forensics

  • Preserve power to DVR/NVR — do not switch off
  • Image using forensic write blocker before viewing
  • Extract logs: access records, time synchronization, remote access history
  • Verify video authenticity — hash the recording file
  • Check IP camera access logs — remote logins may indicate tampering

Cloud-Stored IoT Data

Most modern IoT devices sync to cloud (Google, Amazon, Apple, Chinese manufacturers). Legal process for cloud data:

  • Google (Nest, Android): google.com/transparencyreport/userdatarequests
  • Amazon (Alexa, Ring): amazon.com/gp/help/customer/display.html
  • Apple (HomeKit): apple.com/legal/privacy/law-enforcement
  • Chinese manufacturers (Hikvision, Dahua): require MLAT

Legal Framework

IoT device seizure follows standard Section 94 BNSS procedure. Cloud data requires Section 91 BNSS notice to Indian office or MLAT for overseas servers. All evidence must be accompanied by Section 63 BSA certificate.

Frequently Asked Questions

Can IoT devices be used as evidence in Indian courts?
Yes. Data from IoT devices — CCTV footage, router logs, smart device activity — is admissible as electronic evidence under BSA 2023 with Section 63 certificate. Hash values must be computed at collection to prove integrity.
How do police access smart speaker data in India?
Law enforcement can request smart speaker data (Alexa, Google Home) from Amazon and Google through their respective LEA portals. Indian legal process (Section 91 BNSS order) is accepted. Data includes voice command history and associated account information.
What evidence can be found in a home router?
Home routers contain DHCP lease logs (device-to-IP mapping), DNS query history (websites visited), connection timestamps, and port forwarding configurations. This data can prove device presence on network and websites visited by any connected device.
