Network Forensics for Cybercrime Investigation — India Guide

Network forensics is the capture, recording, and analysis of network packets and logs to identify, investigate, and prosecute cybercrime. In India, network evidence is increasingly accepted in courts with proper chain of custody. This guide covers the essentials.

Network Evidence Sources

  • Packet captures (PCAP): Full packet captures from network taps or endpoint agents
  • NetFlow/IPFIX: Traffic metadata without payload — who talked to whom, when, how much
  • Firewall logs: Allow/deny decisions with source/destination IPs and ports
  • DNS logs: Domain lookups — reveals C2 communication and malicious domains
  • Proxy logs: HTTP/HTTPS requests through corporate proxy
  • ISP CDR: Call Detail Records extended to internet sessions

Tools for Network Forensics (Free)

  • Wireshark — industry standard packet analyzer
  • Zeek (Bro) — network security monitor, extracts metadata
  • NetworkMiner — passive network sniffer, reassembles files
  • Suricata — IDS/IPS with PCAP logging
  • tcpdump — command-line packet capture

Key Wireshark Filters for Investigation

  • http.request.method == "POST" — form submissions, data exfiltration
  • dns.qry.name contains "suspicious.domain" — C2 DNS lookups
  • ip.addr == 192.168.1.100 — filter by suspect IP
  • tcp.port == 4444 — common malware ports
  • frame contains "password" — credential exposure in plaintext

ISP Data Requests in India

ISPs in India are required to maintain internet session logs (subscriber → IP mapping) for 12 months. Requests must be made with:

  • Court order or Section 91 BNSS notice
  • Specific IP address, date, and time in UTC
  • Official letterhead signed by SP or higher

Evidence Admissibility

Network evidence under BSA 2023 Section 63 requires certificate from:

  • Network administrator who captured the data
  • SIEM/firewall vendor if logs from commercial system
  • Hash value of captured PCAP files
  • Detailed chain of custody documentation

Frequently Asked Questions

What is network forensics in cybercrime investigation?
Network forensics involves capturing, preserving, and analyzing network traffic (packets, logs, DNS queries) to investigate cybercrimes. It reveals communication between attacker and victim systems, data exfiltration paths, and C2 server connections.
Can Wireshark be used for court evidence in India?
Yes, Wireshark captures (PCAP files) are accepted as evidence in Indian courts when accompanied by a Section 63 BSA 2023 certificate from the person who conducted the capture, along with SHA-256 hash values for integrity verification.
How do I request internet logs from ISP in India?
Submit a Section 91 BNSS notice or court order to the ISP's nodal officer. Provide the suspect's IP address, date, and time (in UTC). ISPs must maintain logs for 12 months per DoT regulations.
