10 OSINT Tools Every Beginner Should Know (and What They Are Actually For)

File No.OD-005/2026
SubjectSurvey of foundational OSINT tooling with lawful use context
CategoryOSINT Fundamentals
AuthorManuj Kumar Pandey
Published2026-05-07
Reading time7 minutes

The OSINT tool landscape is overwhelming. These ten free or freemium tools cover 90% of beginner needs — explained by what investigative question each one answers.

Tools answer questions — start with the question

Beginners collect tools the way some people collect gym memberships. The professional approach is the reverse: identify the investigative question, then pick the tool that answers it. Below, each tool is framed by the question it exists to answer. All are usable free of charge at entry level, and all operate on publicly available data.

1. Google (advanced operators) — "What has been indexed about this subject?"

Still the most powerful OSINT tool ever built. Operators like site:, filetype:, intitle: and exact-phrase quotes turn a general search engine into a precision instrument — for example, restricting results to PDF documents on a specific organisation's website. Learn ten operators well before installing anything else.

2. Have I Been Pwned — "Has this email appeared in a known breach?"

A free breach-notification service maintained by security researcher Troy Hunt. Essential for self-audits and for security teams checking organisational exposure. It deliberately does not reveal passwords — it tells you that exposure happened and in which breach.

3. Whois / RDAP lookups — "Who registered this domain, and when?"

Domain registration records reveal creation dates, registrars and (where not privacy-protected) registrant details. A "bank" website registered eleven days ago tells you everything you need to know. Historical whois services extend this back in time, showing ownership changes.

4. Wayback Machine — "What did this page say before it was edited or deleted?"

The Internet Archive's snapshots preserve deleted pages, changed terms, vanished team pages and scrubbed claims. In fraud and due-diligence work, comparing a company's website across years is frequently more revealing than its current version.

5. Reverse image search — "Where else has this photo appeared?"

Google Lens, Bing Visual Search, TinEye and Yandex each index different corners of the web. The core verification use: checking whether a "news" photo, profile picture or product image was lifted from somewhere else years earlier. We cover full methodology in a separate article.

6. Shodan — "What devices and services is an organisation exposing to the internet?"

Shodan indexes internet-connected devices and services — webcams, routers, industrial systems, misconfigured databases. Defensively, security teams use it to discover their own organisation's forgotten, exposed assets. Important: viewing an index entry is lawful; connecting to or accessing systems you do not own is not.

7. theHarvester — "What emails, subdomains and hosts are publicly associated with a domain?"

A classic open-source reconnaissance tool that aggregates results from search engines and public sources to map an organisation's external footprint. Standard in authorised security assessments, where it shows what an attacker could enumerate without touching the target.

8. Maltego (Community Edition) — "How do these entities connect?"

A link-analysis platform that visualises relationships between people, domains, companies, email addresses and infrastructure as a graph. Its real value is cognitive: investigations involving more than a handful of entities become unmanageable in notes, but obvious in a graph.

9. ExifTool — "What metadata is inside this file?"

Photos and documents carry embedded metadata: camera model, timestamps, software used, sometimes GPS coordinates. ExifTool reads (and strips) it. Investigators use it to verify when and how a file was produced; privacy-conscious users use it to clean their own files before sharing.

10. Nominatim / Google Earth — "Where was this taken?"

Geolocation — matching features in a photo (terrain, signage, architecture, shadows) to map and satellite data — is one of the most powerful verification skills in modern OSINT, used heavily in conflict reporting and disinformation debunking. Free mapping tools are all you need to start practising with publicly posted images.

The rules that apply to all of them

Three boundaries, always: (1) Use tools only on data you may lawfully access — your own assets, authorised engagements, or genuinely public information. (2) Document everything: a finding you cannot reproduce or source is worthless. (3) A tool's output is a lead, not a conclusion — verify across independent sources before you treat anything as fact.

Master these ten and you will understand the underlying categories — search, breach data, infrastructure, archives, imagery, link analysis, metadata — that every advanced commercial platform is built on.
