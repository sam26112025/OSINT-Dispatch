Using Burp Suite for Web Application Security Testing: A Beginner's Workflow

File No.IGRS-040/2026
SubjectPractical introduction to Burp Suite Community Edition for authorized web application testing
CategoryThreat Intelligence
AuthorManuj Kumar Pandey
Published2026-04-06
Reading time6 minutes

Burp Suite is the industry-standard tool for web application security testing. The essential workflow for beginners doing authorized assessments.

What Burp Suite does

Burp Suite sits between your browser and the target application, intercepting, analysing, and manipulating HTTP/HTTPS traffic. It combines a proxy, request repeater, scanner, and intruder into a single platform. The Community Edition is free and covers core functionality for most web application testing work.

Setup

Burp Suite operates as an HTTP proxy on localhost:8080 by default. Configure Firefox to route traffic through this proxy via Network Settings. For HTTPS sites, install Burp's CA certificate from Proxy → Proxy Settings → CA Certificate, then install in your browser's certificate store.

The intercept workflow

With the proxy configured, every request passes through Burp. Turn on Intercept (Proxy → Intercept is on). Each request pauses showing full headers, parameters, and body. You can modify any aspect before forwarding — this is how testers inject SQL injection strings, XSS payloads, and path traversal sequences into parameters to test for vulnerabilities.

The Repeater — your most used tool

Send any captured request to Repeater (right-click → Send to Repeater). Modify the request and resend. The response appears side-by-side. Iterate across multiple modifications to identify how the application handles different inputs. This iterative process is how most manual vulnerability discovery happens.

All testing must be performed only on systems you have written authorization to test. Running Burp Suite against a web application without authorization constitutes unauthorized access under Section 66 IT Act regardless of whether vulnerabilities are found.
