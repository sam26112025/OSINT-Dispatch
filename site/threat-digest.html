RoguePlanet — Microsoft Defender Zero-Day, No Patch Available
CRITICALIndia High Risk
A researcher released a new Defender zero-day (RoguePlanet) exploiting a race condition to achieve SYSTEM privilege escalation on fully patched Windows 10 and 11. Released on June 10, the same day as Patch Tuesday — no Microsoft patch available as of June 13. ThreatLocker independently confirmed the exploit works. Detection: monitor for MsMpEng.exe spawning any child process — this should never occur in a healthy environment.
Detection Pivot
Parent: MsMpEng.exe spawning child EventID 4688 — SYSTEM integrity shell CVE-2026-33825
▶ Mitigation
Enable application allowlisting (blocks by default). Restrict local user privileges. Monitor MsMpEng.exe process lineage. Apply June 2026 Patch Tuesday for other fixes while awaiting RoguePlanet patch. Full article: IGRS Analysis

ServiceNow Data Breach — Silent Patch Left Enterprises Unaware 4 Days
HIGHIndia Relevant
ServiceNow patched a critical unauthenticated API vulnerability on June 5 but only notified customers via a behind-login advisory on June 9. Attackers queried customer instance data — IT tickets, employee records, security incident reports. Multiple large Indian IT and BFSI enterprises use ServiceNow.
▶ Action
Check ServiceNow customer portal for KB3067321. If you received a support case from ServiceNow, initiate incident response. Review API access logs for April–June 2026. CERT-In notification required if personal data was exposed.

Turning a Threat Digest Into Action

A threat digest is only valuable if it changes what you do. The discipline is to read for relevance rather than novelty: a vulnerability or campaign matters to you in proportion to your exposure to the affected technology, the sensitivity of the assets involved, and evidence that the threat is being actively exploited. Most items in any digest will not apply to your environment, and recognising that quickly is part of the skill.

For Indian organisations, the most actionable inputs are CERT-In advisories, sector-specific alerts from regulators such as the RBI for financial entities, and confirmed active-exploitation signals. When an item is relevant, convert it immediately into a concrete step — a patch ticket, a detection rule, a block, or a briefing — and record the decision. Intelligence that is read but never operationalised provides no protection.
